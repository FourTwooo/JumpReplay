## 已接入的功能

1. 首页菜单可添加捕获快捷设置磁贴。Android 13 起请求系统添加；较早系统提示手工添加。磁贴与首页共享全局捕获状态，目标 App 中原有注入悬浮窗仍只控制当前进程。
2. 新增“快捷动作”页。可以手工输入、粘贴 Scheme / Intent URI，从文件导入，或从捕获 / 收藏详情、意图编辑页保存动作。可自定义名称、应用 / 图片图标、动态替换参数及现有启动模式。
3. 动作保存完整 Intent 快照和必要来源信息，不依赖原收藏记录继续存在。旧快捷方式的载荷及启动入口保持兼容；动作执行复用透明 ShortcutActivity、ReplayTasks 和 ShortcutLaunchCoordinator。
4. 动作备份支持导出 / 导入完整快照、图标和参数定义。采用逐条读写和数据库事务；损坏的备份不会留下部分导入结果。导入产生新动作 ID，不覆盖现有动作或更改已有组件选择。
5. 桌面 StackView 叠卡支持上下滑动、点击执行、独立选择及排序、重新配置。多个组件各自保存动作列表；动态参数仍通过透明 Activity 弹窗输入。动作修改后更新组件及关联的固定快捷方式。
6. 捕获监视窗默认关闭，在首页菜单开启选项并授予悬浮权限后使用。只在捕获开启且主应用退到后台时出现；回到应用收起。停止 / 暂停捕获立即移除窗口并结束捕获前台服务。关闭监视窗本身只关闭显示选项。
7. 配置“所有”列表按 Intent、Scheme、其他类别稳定分组，只排序展示副本，保留保存配置的原始顺序和开关。

## 真机验收

- 监视窗选项开启、全局捕获关闭时退到桌面：没有本应用的悬浮窗口，没有 CaptureSessionService。
- 捕获开启后退到桌面：出现监视窗；回到应用：窗口收起。
- 在监视窗中暂停：捕获状态变为关闭，窗口与捕获前台服务结束。
- 首页关闭捕获或快捷磁贴关闭捕获后退到桌面：窗口不再出现。
- OnePlus 桌面接受固定组件请求并自动打开配置页；选择三个测试动作后，真实上下滑动切换，点击卡片成功进入系统设置。
- OnePlus 快捷设置面板中的 JumpReplay 磁贴实际切换捕获状态，关闭时停止后台监视窗口及捕获前台服务。
- 真机动态参数弹窗输入 `hello world&x=1`，普通模式启动后接收编辑页显示 `jumpreplay://qa?value=hello%20world%26x%3D1`，确认输入不会被拆成新的 URI 参数。
- 真机跨 APK 参数回归测试通过：第三方 Parcelable、Serializable、嵌套字段、数组、集合、Map、Long 精度、null、循环引用与共享引用，在编辑、快捷方式存取、动作存储、备份导入、普通模式重放后保持预期值。使用独立 compatibility fixture APK，未把其自定义数据类编入主应用。40 万字符字段也经过原有完整链路验收。

真机原 APK 和完整数据已保留；安装采用保留数据的更新，没有重启真机或改动系统框架 Hook。本轮对 IntentCapture / ActivityCaptureHooks 的系统安装路径没有修改。

测试创建了 `QA_WiFi`、`QA_Bluetooth`、`QA_Settings`、`QA_Dynamic` 四条动作和一份测试桌面组件，供实际体验。它们是测试数据，可以在动作页删除；没有给新安装用户预置这些内容。

## Android 13 补测

Android 13 的参数管道复测发现旧代码使用 EOF 判断 JSON 消息结束，遇到延迟释放的管道写端时会等待超时。现在完整读出一个 JSON 对象即返回，通信格式保持不变，并保留 Integer / Long 区别。已在原目标进程未重启的情况下验证旧端点兼容，另有保留写端不关闭的管道测试覆盖此问题。

API 33 原生环境中，40 万字符字段的编解码、离线及原进程编辑校验通过；但旧测试直接发起约 801816 字节 extras 的 Activity 被系统以 Transaction too large 拒绝，导致那次完整测试失败，该结果没有计为通过。随后单独补测仍以 40 万字符做编解码校验，仅将测试夹具实际 Activity 发起字段设为 10 万字符，完整自定义对象的动作保存、导入和启动链路通过。产品代码没有静默裁剪参数；系统 Binder 限制仍然适用。

另记录一项原有兼容性边界：API 33 中没有声明主应用可见性的测试目标会出现配置 Provider / Messenger 服务不可见。为验证主应用监视计数，测试夹具明确声明了该包的可见性后，真实 Hook 捕获记录能够入库并更新计数。该现象未通过改变框架 Hook 或限制原有开放 IPC 来掩盖，也未据此宣称所有高版本目标应用都已验证。
