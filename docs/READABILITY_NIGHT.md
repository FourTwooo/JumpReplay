# 详情、空白提示与夜间模式

基于 `744f8a949d77b30ada06b11907e94e4f1eac0453`，保留用户设置的版本号 `1.6.5`，测试包标识为 `1.6.5-readability.1`。

- 详情字段采用上下排列：小号字段名、完整宽度的字段值，增加行距与行间留白。字段值及堆栈使用等宽字体，长链接和包名自动换行，复制值时保留原文。
- 字段与调用堆栈入口位于摘要下方。顶部摘要最多展示四行，长按可复制全文；调用堆栈支持滚动和长按全文复制。原有字段长按复制 Key/Value 保留。

- 背景、主要/辅助文字、输入框、分隔线及触摸反馈采用统一的日间/夜间资源。修复 API 21 主题覆盖、固定白底和深色模式的低对比文字；夜间开关选中态使用浅蓝色。配置、禁用、重放、设置、历史及抽屉使用相同配色来源。
